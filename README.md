# VoRD ontology sources

VoRD is an RDF vocabulary for describing operational restrictions of SPARQL
services.

See github pages for ontology details.

This repository contains the ontology source set:

- `vocab/vord.ttl` — the authoritative VoRD vocabulary
- `shapes/vord.shacl.ttl` — SHACL validation shapes
- `shex/vord.shex` — the ShEx schema
- `spec/index.html` — the VoRD vocabulary usage specification
- `examples/` — basic, exhaustive, and Wikidata rate-restriction examples

The VoRD namespace is `https://w3id.org/vord#`.
